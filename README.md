## 📌 About the Project

StudentHub is a student management application designed to organize student information through a simple dashboard interface. It provides dedicated sections for student records, analytics, and reports.

## ✨ Features

- 📊 **Dashboard** — Overview of student statistics.
- 👨‍🎓 **Student Records** — View and manage student information.
- ➕ **Student Management** — Add, edit, view, and delete records where implemented.
- 📈 **Analytics** — Visualize student-related data.
- 📑 **Reports** — Access the reports section.
- 🎨 **User Interface** — Clean dashboard layout with navigation.

## 🛠️ Tech Stack

- React
- JavaScript
- Vite
- React Router
- Lucide React
- Recharts

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before starting.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/bindusreeseetha/StudentHub.git
```

**2. Navigate to the frontend folder**

```bash
cd StudentHub/frontend
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL** displayed in your terminal.
